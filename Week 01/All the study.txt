The Actual Formula

For two vectors:
a=(ax,ay),b=(bx,by)
a=(ax​,ay​),b=(bx​,by​)

The dot product is:
a⋅b=axbx+ayby
a⋅b=ax​bx​+ay​by​

For your vectors:
(2,3)⋅(1,−1)=2×1+3×(−1)=2−3=−1
(2,3)⋅(1,−1)=2×1+3×(−1)=2−3=−1

The negative result tells us the vectors point more in opposite than in the same direction.

There's also a deeper geometric interpretation:
a⋅b=∣a∣ ∣b∣ cos⁡(θ)
a⋅b=∣a∣∣b∣cos(θ)

where:

    ∣a∣∣a∣ and ∣b∣∣b∣ are the lengths of the vectors,

    θθ is the angle between them.

This explains why:

    angle <90∘<90∘ → cos⁡(θ)cos(θ) is positive → positive dot product,

    angle =90∘=90∘ → cos⁡(θ)=0cos(θ)=0 → dot product is zero,

    angle >90∘>90∘ → cos⁡(θ)cos(θ) is negative → negative dot product.

This formula is used throughout machine learning, computer graphics, robotics, and physics.
Why NumPy Uses Arrays

You might wonder why we write:

np.array([2,3])

instead of:

x = 2
y = 3

Because computers work best when related values are stored together. A NumPy array lets Python treat the vector as one mathematical object, making operations like addition, scaling, dot products, and matrix multiplication efficient and easy.
Why Machine Learning Loves Vectors

Almost everything in ML becomes a vector:

    An image is a huge vector of pixel values.

    A sentence can be represented as a vector (an embedding).

    A user's preferences become a vector.

    Model parameters are stored as vectors.

    Gradients are vectors.

    Neural network weights are vectors and matrices.

Linear algebra is the language that lets machines reason about all of these.

I'm glad you asked again, because this is the question that separates understanding machine learning from just memorizing formulas.

Let's think about it like a professor, from first principles.
Step 1: What is our goal?

Suppose we want to predict house prices.

Our model is
y^=wx+b
y^​=wx+b

This is our original function (also called the model).

It takes an input xx and produces a prediction.

For example:

House size = 1200 sq ft

Model predicts = $250,000

The model has done its job: it made a prediction.

But now ask yourself:

    Is $250,000 good or bad?

The model cannot answer that.

It only knows how to predict.
Step 2: We compare with reality

Suppose the true price is

Actual = $280,000

Now we can measure the mistake.

Prediction = 250,000

Actual = 280,000

Error = -30,000

Now we know the prediction was wrong.
Step 3: We create the loss function

For example:
L=(y^−y)2
L=(y^​−y)2

This function measures how bad the prediction is.

If prediction equals reality:

Prediction = 280,000

Actual = 280,000

Loss = 0

Perfect.
So what are we trying to improve?

Ask yourself:

Do we want to change

The prediction?

No.

Or do we want to reduce

The mistake?

Yes.

The mistake is represented by the loss.
Imagine taking an exam

Suppose you answer

Q1 = B
Q2 = C
Q3 = A

Those answers are like the model's predictions.

Now the teacher grades them.

Score = 30/100

What do you want to improve?

Your answers.

Why?

Because your score is low.

Notice something important:

You don't change your answers because the answers themselves are "bad."

You change them because the score tells you they are bad.

The score (loss) is what guides improvement.
What if we differentiate the model?

Our model is
y^=wx+b
y^​=wx+b

Differentiate with respect to ww.
∂y^∂w=x
∂w∂y^​​=x

Suppose

x = 5

Then

Derivative = 5

What does that tell us?

It tells us:

    If I increase ww, the prediction increases.

That's useful information about the model's behavior.

But it says nothing about whether increasing the prediction will make the prediction more accurate.
Example

Suppose

Prediction = 20

Actual = 100

The derivative of the model says

Increase w → prediction goes up

Great.

That happens to be the correct direction.

Now another example.

Prediction = 120

Actual = 100

The derivative of the model is still

Increase w → prediction goes up

But this time, increasing the prediction makes things worse.

You actually need to decrease the prediction.

The derivative of the model cannot tell the difference between these two situations.

Why?

Because it never looks at the actual answer.
The loss function does

The loss is
L=(y^−y)2
L=(y^​−y)2

Notice it contains both:

    prediction (y^y^​)

    actual answer (yy)

When we differentiate the loss, the gradient depends on both.

That means the gradient changes depending on whether the prediction is too high or too low.

This is exactly what we need.
Think of a GPS

Your model is like your current location.

You are here.

Your destination is the correct answer.

The loss is the distance to the destination.

If your GPS only tells you

Current location:

Can you reach your destination?

No.

You also need to know

How far am I from the destination?

The derivative of the loss is like the GPS saying:

    "Turn left."

It uses both your location and the destination to compute the direction.
The chain of information

Input (X)
      │
      ▼
Model
ŷ = wx + b
      │
      ▼
Prediction
      │
      ▼
Compare with Actual y
      │
      ▼
Loss
      │
      ▼
Derivative of Loss
      │
      ▼
Update w and b

Notice that the actual answer first appears in the loss.

That's why we differentiate the loss.
A mathematical view

The loss is
L=(wx+b−y)2
L=(wx+b−y)2

Notice something important.

The model is inside the loss.

When we compute
∂L∂w
∂w∂L​

we are actually differentiating
(wx+b−y)2.
(wx+b−y)2.

So the derivative still knows about the model, because the model is part of the loss function.

In other words:

    We are not ignoring the original function.

    We are differentiating a function that contains the original function.

This is why the chain rule is used.
The most important sentence

Think of it this way:

    The model answers: "What do I predict?"

    The loss answers: "How wrong is that prediction?"

    The derivative of the loss answers: "How should I change my parameters to become less wrong?"

Only the third answer tells us how to learn.
One final intuition

Imagine you and I are playing darts.

The model is your throw.

The bullseye is the correct answer.

Would a coach tell you:

    "Throw differently because that's how your arm moves."

No.

The coach first looks at how far your dart landed from the bullseye, and then tells you how to adjust.

Machine learning does the same thing.

The loss measures the miss, and the derivative of the loss tells the model how to adjust its throw so that the next prediction lands closer to the target.
